# لقيتة — موقع عربي للمفقودات والموجودات

موقع ويب عربي RTL بواجهة حديثة وخلفية Django/Python. يعمل البحث والحسابات والبلاغات والرسائل والصلاحيات على الخادم مع قاعدة SQLite محلية. الواجهة بلا JavaScript مخصص؛ تبديل الوضع الفاتح والليلي يُحفظ في جلسة Django.

## ما يتضمنه

- الصفحة الرئيسية، البحث النصي والتصفية، وتفاصيل البلاغات المنشورة.
- التسجيل والتحقق من البريد وتسجيل الدخول واستعادة كلمة المرور.
- بلاغات المفقودات والموجودات، ملاحظات تحقق خاصة، لوحة المستخدم، وتعديل البلاغ أو إغلاقه.
- مراجعة البلاغات للمشرفين، طلبات التواصل والرسائل الخاصة، الحظر والإبلاغ عن الإساءة.
- حماية CSRF، التحقق من صلاحيات مالك البلاغ، وتحديد معدل الطلبات.
- وضع ليلي ونهاري محفوظ في جلسة الخادم.
- خط Tajawal محلي بأوزان 400 و500 و700 و800، فلا يعتمد تحميل الخط على خدمة خارجية. ملف الرخصة والإسناد موجودان في `backend/static/fonts/`.
- SQLite محلية افتراضيًا؛ لا يلزم إعداد خدمة قاعدة بيانات خارجية للتشغيل المحلي.

## تشغيل محلي

يتطلب Python 3.12 أو أحدث. من مجلد المشروع:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
export DJANGO_DEBUG=true
export REQUIRE_EDGE_PROXY=false
export PUBLIC_AUTH_ENABLED=true
export DJANGO_SECRET_KEY='غيّر-هذه-القيمة-محليًا-ولا-تستخدمها-في-الإنتاج'
.venv/bin/python backend/manage.py migrate
.venv/bin/python backend/manage.py runserver 0.0.0.0:8000
```

افتح `http://127.0.0.1:8000/`. تُنشأ قاعدة SQLite تلقائيًا داخل `backend/`، وتضيف الهجرة الأولية التصنيفات. يتيح `PUBLIC_AUTH_ENABLED=true` التسجيل والبلاغات في التطوير المحلي؛ وعند التسجيل يعرض إعداد التطوير رابط التحقق في سجل الخادم بدل إرسال بريد حقيقي.

## حدود النشر

- إعدادات الإنتاج تقفل التسجيل والبلاغات والتواصل إلى أن يجهز بريد موثّق وإعداد نشر آمن.
- رفع الصور معطّل إلى أن يتوفر مخزن خاص ودائم ومراجع.
- لا تعرض الصفحات العامة تفاصيل التحقق الخاصة أو بيانات الاتصال الحساسة.
- لا تستخدم إعدادات التطوير أو مفتاح `DJANGO_SECRET_KEY` المثال في خدمة عامة.
- الحزمة قابلة للتشغيل والفحص محليًا؛ إعدادها لا يعني نشر الموقع أو تهيئة خدمات الإنتاج.

## التحقق

اجتازت هذه النسخة فحص إعداد Django واختبارات المشروع الـ32، بما فيها اختبار تبديل الوضع الليلي وحماية إعادة التوجيه. هذه النتائج تخص بيئة التطوير هنا ولا تمثل اعتمادًا أمنيًا مستقلًا أو نشرًا عامًا.
