# لقيتة | Laqeeta — منصة عربية للمفقودات والموجودات

> «ضاع منك؟ لقيتة.»

منصة ويب عربية متكاملة لربط أصحاب الأشياء المفقودة بمن عثر عليها، مصممة وفق أرقى معايير تجربة المستخدم العربية، مع التزام صارم بالخصوصية والسلامة، ومبنية كليًا بدون أي أطر أو مكتبات JavaScript في الواجهة الأمامية.

---

## 1. التقنيات المستخدمة

- **الواجهة الأمامية (Frontend):**
  - **HTML5** فقط لبناء هيكل الصفحات والنماذج.
  - **CSS3** للتصميم المتجاوب (Mobile First) وشبكة Grid والبطاقات والتنسيق العربي RTL.
  - **خط تجوال (Tajawal)** بأوزان محليّة (400, 500, 700, 800) مدمجة في المجلد الثابت دون اعتماد على خطوط خارجية.
  - **خالٍ تمامًا من JavaScript:** لا وجود لأي ملف `.js` أو سكربت مضمن أو React أو Vue أو Bootstrap أو Tailwind في الواجهة الأمامية.
  - **تبديل الوضع الليلي والنهاري:** يتم عبر الخادم وتُحفظ الجلسة في `Django Session` دون استخدام JavaScript.

- **الواجهة الخلفية (Backend):**
  - **Python 3** مع إطار العمل **Django 5**.
  - **Django ORM** للتعامل مع النماذج والاستعلامات.
  - **Django Forms & Validation** للتحقق الصارم من المدخلات ومكافحة التلاعب.
  - **Django Authentication** لإدارة المستخدمين والتسجيل الآمن وجلسات الدخول.
  - **Django Admin** للوحة تحكم المشرفين وإدارة البلاغات ومراجعتها.

- **قاعدة البيانات (Database):**
  - **PostgreSQL** عبر متغير البيئة `DATABASE_URL` (متوافق تمامًا مع Neon و Render Postgres).
  - دعم تلقائي لـ **SQLite** أثناء التطوير المحلي عند عدم تمرير رابط قاعدة البيانات.

## 3. الصفحات الـ 21 المكتملة

1. **الصفحة الرئيسية (`/`):** تتضمن شريط التنقل، القسم الرئيسي Hero، الرسم الدائري المميز، صندوق البحث الكبير، أحدث البلاغات المنشورة، قسم كيف تعمل المنصة، قسم الخصوصية والسلامة، والتذييل.
2. **صفحة المفقودات (`/lost/`):** استعراض مخصص لبلاغات الأشياء المفقودة مع مرشحات البحث والتصنيف والمنطقة.
3. **صفحة الموجودات (`/found/`):** استعراض مخصص للأشياء المعثور عليها مع التصفية والبحث.
4. **صفحة البحث والنتائج (`/search/`):** محرك بحث وتصفية متعددة الحقول وتقسيم النتائج إلى صفحات (Pagination).
5. **صفحة تفاصيل البلاغ (`/reports/<uuid>/`):** عرض الوصف العام، الموقع، التصنيف، نموذج طلب التواصل، وزر الإبلاغ عن إساءة.
6. **صفحة إنشاء حساب (`/accounts/signup/`):** تسجيل مستخدم جديد مع التحقق من تطابق كلمات المرور والموافقة على الشروط.
7. **صفحة تسجيل الدخول (`/accounts/login/`):** تسجيل الدخول الآمن بالبريد وكلمة المرور المشفرة.
8. **صفحة استعادة كلمة المرور (`/accounts/password/reset/`):** طلب إعادة التعيين مع صفحات التأكيد والإكمال.
9. **صفحة التحقق من البريد (`/accounts/verification-sent/` و `/accounts/verify/<uid>/<token>/`):** توثيق البريد وتفعيل الحساب.
10. **صفحة إنشاء بلاغ (`/reports/new/`):** نموذج إنشاء بلاغ جديد (مفقود / موجود) مع حقل ملاحظات التحقق السرية المنفصل.
11. **صفحة تعديل البلاغ (`/reports/<uuid>/edit/`):** تعديل البلاغات النشطة مع إعادتها لقيد المراجعة.
12. **لوحة المستخدم (`/me/` أو `dashboard`):** إحصائيات البلاغات (الكل، المعلقة، المنشورة، المغلقة)، جدول البلاغات، وروابط الإجراءات.
13. **صفحة الرسائل الداخلية (`/inbox/`):** استعراض جميع المحادثات الجارية للمستخدم.
14. **صفحة تفاصيل المحادثة (`/inbox/<uuid>/`):** إرسال واستقبال الرسائل النصية بين الطرفين بخصوصية تامة بدون كشف أرقام الهواتف أو البريد.
15. **صفحة إعدادات الحساب (`/accounts/settings/`):** تعديل الاسم المعروض، مراجعة حالة التوثيق، وتاريخ الانضمام.
16. **صفحة إرشادات السلامة (`/safety/`):** توجيهات التحقق قبل التسليم، اختيار الأماكن العامة، وحفظ العلامات السرية.
17. **صفحة سياسة الخصوصية (`/privacy/`):** تفصيل حماية البيانات العامة والخاصة وتشفير كلمات المرور.
18. **صفحة شروط الاستخدام (`/terms/`):** التزامات المستخدمين، المحتوى المحظور، وصلاحيات الإشراف.
19. **صفحة الإبلاغ عن إساءة (`/reports/<uuid>/abuse/`):** تقديم شكوى ضد البلاغات المخالفة أو المسيئة.
20. **صفحة خطأ 404 (`404.html`):** صفحة أنيقة عند عدم العثور على البلاغ أو المسار.
21. **صفحة خطأ 500 (`500.html`):** معالجة أخطاء الخادم غير المتوقعة بواجهة لائقة.

## 4. التشغيل المحلي السريع

### المتطلبات
- Python 3.10 أو أحدث.

### خطوات التشغيل:
```bash
# 1. الانتقال إلى مجلد الخادم
cd laqeeta/backend

# 2. إنشاء بيئة وهمية وتفعيلها
python3 -m venv .venv
source .venv/bin/activate

# 3. تثبيت الاعتماديات
pip install -r requirements.txt

# 4. ضبط متغيرات بيئة التطوير
export DJANGO_DEBUG=true
export REQUIRE_EDGE_PROXY=false
export PUBLIC_AUTH_ENABLED=true
export DJANGO_SECRET_KEY='django-insecure-laqeeta-local-development-key-32-chars-long-minimum'

# 5. تطبيق الهجرات وقاعدة البيانات
python manage.py migrate

# 6. زرع البيانات التجريبية والحسابات الأولية
python manage.py seed_demo_data

# 7. تشغيل خادم التطوير
python manage.py runserver 0.0.0.0:8000
```
افتح المتصفح على: `http://localhost:8000/`

## 6. الربط بقاعدة بيانات Neon PostgreSQL

لربط التطبيق بقاعدة بيانات PostgreSQL سحابية على Neon:
1. أنشئ قاعدة بيانات جديدة على [neon.tech](https://neon.tech).
2. انسخ رابط الاتصال (Connection String) بصيغة:
   ```env
   DATABASE_URL="postgresql://<user>:<password>@<ep-xyz>.neon.tech/<dbname>?sslmode=require"
   ```
3. عيّن المتغير في البيئة أو في ملف `.env`:
   ```bash
   export DATABASE_URL="postgresql://<user>:<password>@<ep-xyz>.neon.tech/<dbname>?sslmode=require"
   python manage.py migrate
   ```
يقوم Django تلقائيًا باستخدام `dj_database_url` لاكتشاف الاتصال وتطبيق جميع الجداول والفهارس على PostgreSQL.

## 7. التجهيز للنشر على Render

التطبيق مهيأ بالكامل للنشر كخدمة ويب على [Render](https://render.com):
1. أضف Web Service جديدة في Render وحدد مسار مستودع المشروع.
2. حدد بيئة التشغيل: **Python 3**.
3. أمر البناء (Build Command):
   ```bash
   pip install -r laqeeta/backend/requirements.txt && python laqeeta/backend/manage.py collectstatic --noinput && python laqeeta/backend/manage.py migrate
   ```
4. أمر البدء (Start Command):
   ```bash
   gunicorn --chdir laqeeta/backend config.wsgi:application --bind 0.0.0.0:$PORT
   ```
5. متغيرات البيئة في Render:
   - `DATABASE_URL`: رابط قاعدة بيانات PostgreSQL المرفقة.
   - `DJANGO_SECRET_KEY`: مفتاح سري عشوائي طويل (50 حرفًا على الأقل).
   - `DJANGO_ALLOWED_HOSTS`: نطاق الخدمة (مثال: `laqeeta.onrender.com`).
   - `DJANGO_CSRF_TRUSTED_ORIGINS`: `https://laqeeta.onrender.com`
   - `SITE_URL`: `https://laqeeta.onrender.com`
   - `DJANGO_DEBUG`: `false`

## 8. الأمان والخصوصية

- **ملاحظات التحقق السرية:** معزولة في جدول `ReportPrivateDetails` ومحمية بصلاحيات المشرف الفائق فقط، ولا تظهر في أي صفحة عامة أو نتائج بحث.
- **الحماية من هجمات CSRF:** مفعلة على كافة النماذج وتستخدم كوكيز آمنة.
- **تحديد معدل الطلبات (Rate Limiting):** تحديد عدد المحاولات للتسجيل والدخول وإنشاء البلاغات لمنع محاولات التخمين والإغراق.
- **التعامل مع الصور:** رفع الصور معطل افتراضيًا حتى يتم ربط مخزن سحابي دائم ومراجع لمنع رفع ملفات ضارة.
